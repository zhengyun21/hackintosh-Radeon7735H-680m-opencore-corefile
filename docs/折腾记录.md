## 二、最终结论：三道墙

### 1. 显卡墙（不可逆）❌
- Radeon 680M 无 macOS 驱动：社区判词 + 本机 7 种配置实测全卡 **DSMOS has arrived 之后**（显示初始化，键盘无反应，真卡死）
- 试过：`-x`（恢复环境不支持）、`agdpmod=pikera radpg=15`、伪装 6600 XT、删伪装、最小化 kext、禁 AppleSMCRTC、`-igfxvesa` —— **全部无效**
- 根因：macOS 10.14+ 删除软件渲染，WindowServer→Core Animation→Metal 全强制 GPU；无 framebuffer = 无 Metal 设备 = 界面永远起不来
- 社区唯一 680M 例外（Reddit r/hackintosh 1xb786j）内容未证实

### 2. NVMe 墙（已解决 ✅ 见下）
### 3. 显示墙 = 显卡墙（不可逆）❌

## 四、关键测试记录

### 显卡（6+ 配置，全部卡 DSMOS 后显示初始化）
1. `-x agdpmod=ignore` → 禁止标志界面
2. `agdpmod=pikera radpg=15` → 卡 lockdown_mode
3. 删伪装 + 清 GPU boot-args → 卡 lockdown_mode
4. 最小化 kext + Reset NVRAM → 过 lockdown_mode，卡 SMCRTC: stop
5. 禁 AppleSMCRTC → 过 SMCRTC，卡 DSMOS 后（最深远度）
6. `-igfxvesa` → 仍卡 DSMOS 后

### NVMe（4 配置全 panic → nvme=-1 解决）
1. 双盘（23:23）→ panic page fault @0x0
2. 单盘 660p 换槽（23:32）→ 同 panic
3. NVMeFix 重开 → 同 panic
4. 换槽 + 只插 Fanxiang → 同 panic
5. **加 `nvme=-1`（23:49）→ `Successfully initialized NVMe drive` ×2，两块盘全过，无 panic ✅**

### 镜像
- 全拔 NVMe：ACMTRM 全流程跑通（TRM Unrestricted / KE ready=YES / DSMOS）→ 卡显示
- 插盘：NVMe panic（nvme=-1 前）/ 卡显示（nvme=-1 后）
